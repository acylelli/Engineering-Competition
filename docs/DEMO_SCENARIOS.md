# Demo Scenarios

## Demo A — 낙상

1. 실제 Wear OS 기기를 착용합니다.
2. 테스트 낙상 동작으로 후보 이벤트를 발생시킵니다.
3. 워치가 진동하고 `괜찮으신가요?` 화면을 표시합니다.
4. 무응답 상태를 유지해 자동 SOS를 발생시킵니다.
5. 보호자 스마트폰에서 Push와 사용자 위치를 확인합니다.

## Demo B — 안전구역

1. 보호자 앱에서 테스트 안전구역을 설정합니다.
2. 사용자가 영역 밖으로 이동합니다.
3. 워치에서 이탈 경고를 확인합니다.
4. 보호자 앱에서 이탈 알림과 현재 위치를 확인합니다.

## Demo C — 귀가

1. 보호자가 사용자 위치를 확인하고 귀가를 요청합니다.
2. 워치가 진동하고 귀가 요청을 표시합니다.
3. 사용자가 `집으로 가기`를 선택합니다.
4. 방향과 남은 거리 안내를 확인합니다.
5. 집 안전구역 진입 후 보호자 도착 알림을 확인합니다.

## 시연 전 체크리스트

- 워치·스마트폰·서버 시간이 동기화되어 있는가
- GPS와 알림 권한이 허용되어 있는가
- FCM 토큰이 최신인가
- 테스트 계정과 워치가 올바르게 연결되어 있는가
- 테스트 장소의 안전구역 반경이 시연에 적합한가
- 네트워크 실패 시 대체 설명 또는 녹화본이 준비되어 있는가
